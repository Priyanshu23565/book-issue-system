📚 Book Issue System
A web-based application built using Spring Boot, MySQL, and JavaScript (Frontend) to manage and track book issues in a library or book loan system. This project allows users to:

Add new users with personal information and book details

View and manage a list of users with book issue and return dates

Edit user details and book information

Delete users and their associated book records

Seamless integration with MySQL for database management

This app supports CRUD operations (Create, Read, Update, Delete) and is designed to be a simple yet effective solution for tracking book issues and returns in a library environment.
